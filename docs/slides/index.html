Everything on the robot is one Viam module with a DoCommand API. Atlas holds the object library and the log of every frame and attempt. The dashboard has one command box, the live camera and the robot’s internal map.

Each row says where its evidence comes from: on the arm or offline. Recognition is not perfect: refusals are not 100 percent reliable, and look-alikes can still be confused.

What is the business value?

Warehouse kitting and returns sorting, lab sample handling, retail restocking, and assistive or home robots.

No per-SKU setup

An operator names the item: no poses to program, no model to train per item.

Shared memory in Atlas

The object library and every grasp attempt persist, and a fleet can share them.

One Viam module

Built to move to another arm or camera through configuration, not code.
